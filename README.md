### 📌 About Me

你好，我是 Gavin，日常在 Java 后端与 Vue 前端之间来回横跳。

从学生时代被代码"支配"，到现在明天接触，最大的变化是：以前追求"能跑"，现在更在意**能不能长期维护**。喜欢把复杂的东西拆小、把重复的东西自动化，也喜欢把折腾的过程写下来分享出去。

- 💡 兴趣：开源项目 / 技术写作 / 哔哩哔哩整活
